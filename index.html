About

SunnysideUp is a Seoul-based software studio that turns ideas into working apps and web services. With more than four years of experience building and operating production services, we take a project from planning through development, store release and maintenance.

We publish our own apps on Google Play and also build apps, web services, API servers and admin tools for clients.
